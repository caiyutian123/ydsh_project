   折算下来明细口径约为订单口径的 2.2 倍，提示**优惠/折扣力度较大或单价与实际支付存在系统性差异**，需在 DWS 层统一口径后再做利润分析。

## 六、用户行为漏斗

| 行为 | 事件数 | 涉及用户数 |
|------|--------|-----------|
| 浏览 | 34,160 | 1,000 |
| 加购 | 8,286 | 1,000 |
| 收藏 | 5,585 | 995 |
| 购买 | 11,969 | 1,000 |

**转化率测算**

- 浏览 → 加购：8,286 / 34,160 = **24.3%**
- 浏览 → 购买：11,969 / 34,160 = **35.0%**
- 加购 → 购买：11,969 / 8,286 = **144.4%**（购买事件多于加购事件）

**洞察**：购买事件数超过加购事件数，说明**大量购买行为是"直接下单"而非"先加购再下单"**，加购不是购买的必要前置路径。这与常规电商漏斗假设不同，运营上应重点优化"浏览 → 直接下单"的转化，而不是只盯加购环节。

## 九、结论与行动建议

| # | 结论 | 建议 |
|---|------|------|
| 1 | 品类、渠道、地域分布均高度均衡 | 无需收缩战线，按品类精细化运营，优先加码运动户外 |
| 2 | 明细口径约为订单实付口径的 2.2 倍 | 在 DWS 层统一"标价 / 实付 / 折扣"口径，避免 GMV 口径混用 |
| 3 | 加购→购买转化率 144%，购买不等于加购后置 | 优化"浏览→直接下单"路径（详情页一键下单、免登录下单） |
| 4 | 门店头尾差距 2 倍，第 9 名起断层 | 对长尾门店做坪效评估，头部门店复制"开封社区店"模型 |
| 5 | TOP10 用户人均消费 3.3 万+、9~14 单 | 建立高价值用户分层（高频型 / 高客单型），差异化权益 |
| 6 | 月度波动仅 18%，促销拉动弱 | 促销策略从"降价"转向"品类组合 + 会员权益" |
